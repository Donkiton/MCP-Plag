# Яндекс Музыка · плагин и MCP

[← MCP-Plag](../README.md) · [Сервер и самостоятельное развёртывание](server/README.md) · [Архивы](releases/)

Поиск музыки, история прослушиваний, рекомендации и управление собственными плейлистами через ChatGPT. Здесь сохранены текущий плагин **1.0.3** и снимок серверной установки на VDSina от **25 октября 2026 года**.

> «Найди спокойный джаз, создай приватный плейлист и добавь выбранные треки».

Это неофициальная интеграция, не связанная с Яндексом. Она работает с каталогом и данными аккаунта; воспроизведения аудио и скачивания музыки в опубликованном наборе инструментов нет.

## Что умеет

| Задача | Инструменты |
| --- | --- |
| Проверить подключённый аккаунт и подписку | `account_info` |
| Найти трек, альбом, исполнителя или плейлист | `search` |
| Получить избранное и историю | `get_liked_tracks`, `get_listening_history` |
| Посмотреть свои плейлисты и треки плейлиста | `list_my_playlists`, `get_playlist_tracks` |
| Посмотреть альбом и популярные треки исполнителя | `get_album_tracks`, `get_artist_tracks` |
| Получить похожие треки, «Мою волну» и чарт | `get_similar_tracks`, `get_my_wave`, `get_chart` |
| Создать приватный плейлист | `create_playlist` |
| Добавить от 1 до 100 треков в собственный плейлист | `add_tracks_to_playlist` |
| Удалить собственный плейлист по явному запросу | `delete_playlist` |

Всего **14 музыкальных инструментов**. HTTP-сервер дополнительно предоставляет служебный `get_profile` для профиля подключённого владельца. Чтение избранного ограничено 500 треками за запрос; остальные операции также имеют параметры размера выдачи. Создание плейлистов, добавление треков и удаление выполняются по запросу пользователя. Если ответ потерян, изменение могло произойти — перед повтором нужно проверить результат в аккаунте.

## Как использовать

Для изучения начните с [серверного руководства](server/README.md). Для установки скачайте нужные ZIP. Для проверки полного комплекта клонируйте репозиторий и выполните из его корня:

```sh
python Yandex.Music/tools/verify_package.py
```

Проверяющая утилита, `provenance.json` и общие контрольные суммы находятся в репозитории и не входят в установочные ZIP. Проверка рассчитана на исходный опубликованный снимок.

Для собственной установки нужны сервер Linux, Python, доступ к API Яндекс Музыки, собственный аккаунт и HTTPS для подключения ChatGPT. Опубликованная установка частная: сервер использует **один аккаунт владельца**, а OAuth проверяет, что подключается именно владелец. Это не готовый сервис для нескольких независимых аккаунтов.

Пакет сохраняет привязку существующего приложения `asdk_app_6ac88e3d727c8191ab80ae2cf2fa5d54` и название «Яндекс». Эти идентификаторы не являются секретами. При самостоятельном развёртывании зарегистрируйте своё приложение, настройте свой endpoint и замените имя/App ID в обоих манифестах и `.app.json`; загрузка ZIP сама по себе не создаёт сервер и не подключает аккаунт. Endpoint установки владельца: `https://77-238-249-144.sslip.io/direct/mcp`.

## Данные и ограничения

Токен Яндекс Музыки хранится на выбранном сервере в файле с правами `0600`; в этой реализации он **не шифруется Fernet**. Служебные базы OAuth и реестр созданных плейлистов остаются на сервере. Ответы с данными аккаунта, плейлистами и историей передаются в MCP-клиент, включая ChatGPT. Администратор сервера имеет доступ к его конфигурации и данным.

В GitHub и ZIP не включены токены, закрытые SSH-ключи, OAuth-сессии, реальные базы и пользовательские музыкальные данные. Исходники содержат адрес и пути существующей установки: при переносе их нужно адаптировать. Работа рекомендаций и каталога зависит от API Яндекса, доступности сервиса и возможностей аккаунта; неофициальная библиотека может потребовать обновлений при изменении API.

Проверка пакетов выполняется без сетевых запросов и без входа в музыкальный аккаунт. Она подтверждает целостность файлов, манифестов, иконок, wheel и архивов; тесты проверяют локальный протокол и жизненный цикл исполнителя. Полный вход через ChatGPT и операции с реальными плейлистами при подготовке этого снимка не повторялись.
