# Снимки Яндекс Музыки

## 2026-10-25 · плагин 1.0.3

- В коллекцию добавлен текущий пакет приложения «Яндекс» 1.0.3 без изменения манифестов и иконки.
- С VDSina сохранены Python-исходники MCP, OAuth HTTP, одноразовый SSH-исполнитель, локальный клиент и вспомогательный socket-исполнитель.
- Сохранены конкретные версии зависимостей, wheel `yandex-music` 3.0.0 и его происхождение. Пакет upstream сообщает `0.1.0`, MCP SDK — `1.30.0`; снимок сервера обозначен датой.
- Добавлены руководство по самостоятельной установке, отдельный пример nginx, инструменты воспроизводимой упаковки и проверки SHA-256.
- Существующие offline-тесты перенесены в `server/tests/`; изменены только путь импорта и поиск каталога инструментов.

В снимок не входят токены, SSH-ключи, базы OAuth, реестр плейлистов, виртуальное окружение, кэши, временные candidate/backup-файлы и сценарии действий с реальным аккаунтом. Подготовка комплекта не выполняет авторизацию, создание/удаление плейлистов, обновление плагина в аккаунте или перезапуск производственных служб.

Проверки целостности и offline-протокола не заменяют проверку чистой установки зависимостей, актуальности API Яндекса и полного подключения ChatGPT к своему серверу.
