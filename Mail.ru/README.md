# @Mail / Mail.ru

Снимок работающего проекта от 11 октября 2026 года: плагин **1.0.10**, MCP-сервер **0.3.21** на VDSina. Все 11 файлов приложения сверены по SHA-256 с `/opt/mailru-mcp/mailru_mcp` на сервере. Конфигурация nginx и systemd взята из действующей установки.

## Состав

- `plugin/` — канонический `plugin.json`, совместимый `.codex-plugin/plugin.json`, привязка к существующему приложению в `.app.json` и четыре PNG для светлой и тёмной тем.
- `server/` — Python-сервер, интерфейс входа, серверные иконки, Roboto с лицензией OFL, тесты, скрипты и примеры развёртывания.
- `releases/` — ZIP плагина и ZIP серверной части, собранные из этих исходников.
- `SHA256SUMS` — контрольные суммы файлов и архивов.
- `tools/verify_package.py` — проверка ссылок манифестов, структуры PNG, интерфейсных ресурсов, состава архивов и контрольных сумм.
- `tools/build_releases.py` — повторная сборка архивов и контрольных сумм из чистых исходников.

## Плагин и иконки

Имя `dev-6aca00f406d4819183ae5ddd3f249497` и App ID в `.app.json` сохранены: это идентификаторы существующего приложения, а не данные авторизации. Пакет предназначен для того же владельца и приложения; перенос на другое приложение потребует его отдельной регистрации и замены привязки.

В обоих манифестах сохранены `logo`, `logoDark`, `composerIcon`, `composerIconDark`. Все четыре файла находятся внутри пакета в `assets/`. Сервер дополнительно содержит `icon.png` (512×512 RGBA) и `login-icon.png`. Иконку owning App платформа хранит отдельно от ZIP: при восстановлении приложения её нужно загрузить отдельно, используя `plugin/assets/logo.png`. После обновления существующего приложения может потребоваться синхронизация инструментов («Refresh tools») и перезагрузка каталога.

## Возможности сервера

Чтение и поиск писем, вложения, папки и метки, черновики, отправка, перемещение, корзина, окончательное удаление, пакетные операции и отписка. Авторизация — OAuth с PKCE; поддерживаются несколько ящиков и шифрование сохранённых паролей приложений. MCP endpoint: `https://mailru-77-238-249-144.sslip.io/mcp`.

Подробности установки и проверки: [server/README.md](server/README.md).

Проверка этого снимка: **138 тестов прошли** на Python 3.12.14, все шесть PNG успешно декодированы, ссылки на ресурсы и оба ZIP проверены. Из корня репозитория проверку комплекта можно повторить командой `python Mail.ru/tools/verify_package.py`. После изменения файлов сначала выполните `python Mail.ru/tools/build_releases.py`.

## Данные авторизации

В этот снимок не входят рабочий `.env`, SSH-ключи, сертификаты и их закрытые ключи, логины подключённых ящиков, пароли, OAuth-токены, SQLite-базы, логи и персональные отчёты. `.env.example` содержит только пустые поля. Адреса и пароли в тестах — вымышленные фикстуры. Учётные данные вводятся на сервере и не должны попадать в Git.
