# Mail / почта Mail.ru

Актуальный комплект от **15 октября 2026 года**: новый плагин **Mail 1.0.0** и MCP-сервер **0.4.0** с **31 командой**. Серверная часть работает на VDSina; её можно развернуть на собственном сервере с HTTPS.

В текущем дереве сохранена только новая регистрация Mail. Прежний плагин и старые ZIP удалены из актуального комплекта; они доступны в истории Git. Версия 1.0.0 относится к новому приложению, а не к откату прежней регистрации.

## Что умеет Mail

- Находить и читать письма, получать вложения, просматривать папки и метки.
- Показывать, читать, изменять и отправлять сохранённые черновики.
- Создавать ответ, ответ всем и пересылку с вложениями; по умолчанию сохранять их как черновики.
- Использовать BCC, HTML и вложения при создании и отправке письма.
- Читать до 20 выбранных писем за запрос и собирать связанную переписку из разных папок, сохраняя статус прочтения.
- Перемещать и архивировать выбранные письма, менять статус «прочитано»; большие операции выполнять в фоне с проверкой результата.
- Создавать и переименовывать папки, удалять пустые пользовательские папки, переносить письма в корзину и отправлять поддерживаемые запросы на отписку.
- По отдельному явному запросу очищать корзину/спам или окончательно удалять выбранное письмо.

Примеры запросов: «Покажи мои черновики», «Ответь всем и сохрани черновик», «Перешли это письмо вместе с вложениями», «Покажи переписку по этому письму», «Архивируй выбранные письма», «Пометь эти письма непрочитанными».

Отправка требует явного запроса пользователя. Сохранённый черновик изменяется с проверкой версии. После SMTP отдельно проверяется копия в «Отправленных»; черновик удаляется только после подтверждённого результата. Постоянная квитанция защищает отправку той же сохранённой версии от повторной доставки после потерянного ответа или перезапуска.

## Проверки и ограничения

Текущий комплект: **192 теста и 20 дополнительных проверок subtest прошли** на Python 3.12.14. Исходники Python совпадают с сохранённым снимком развёрнутого релиза 0.4.0. При его развёртывании прошли ещё 26 проверок на реальном ящике. Подготовка этого комплекта для GitHub не повторяет операции с почтой и не перезапускает службу.

Ограничения вложений: до 20 файлов, до 5 МБ на файл, до 8 МБ суммарно и до 12 МБ итогового MIME-письма. Чтение отдельного вложения ограничено 2 МБ. Переписка определяется служебными идентификаторами, может требовать продолжения и возвращать неполный результат. Нет наблюдения за почтой, истории изменений, отложенной отправки, шаблонов и подписей. Формы отписки с CAPTCHA или отдельным входом могут требовать ручного действия.

Из корня репозитория:

```sh
python Mail.ru/tools/build_releases.py
python Mail.ru/tools/verify_package.py
```

## Данные авторизации

В репозиторий не входят рабочий `.env`, ключи, логины подключённых ящиков, пароли, OAuth-токены, базы, логи и персональные отчёты. `.env.example` содержит пустые поля или примеры; адреса и пароли в тестах вымышлены. Пароли приложений хранятся на выбранном сервере в зашифрованном виде с помощью Fernet. В SQLite также сохраняются служебные данные авторизации, фоновые задания и квитанции отправки черновиков. Базу и ключ шифрования нужно сохранять отдельно от исходников.
