# Состояние @tg на 25 октября 2026 года

Опубликован снимок реализованной интеграции. Сервер запущен на VDSina по HTTPS; личный App-backed плагин версии 1.0.2 зарегистрирован с утверждённой круглой иконкой. Исходники MCP-сервера и переносимого пакета имеют версию 0.1.0.

## Проверено

- Typecheck и 923 теста в 93 отдельных Bun-процессах прошли без ошибок. После исправления импорта необязательного frontend-каталога повторно прошли typecheck и 26 затронутых тестов; серверный архив действительно запущен без app/ и web/.
- Проверены HTTPS, OAuth discovery, требование авторизации на /mcp, loopback listener, состояние systemd и отдельные права на конфигурацию и данные.
- Пакеты пересобираются воспроизводимо. Проверяются состав, контрольные суммы, PNG/ICO, пути всех объявленных изображений и бюджет отдельного App upload. Пять публичных иконок совпали с локальными файлами по SHA-256.
- В тёмной теме визуально проверены крупный логотип карточки, иконка в списке установленных и малая иконка приложения. Необязательный skill, у которого веб-клиент игнорировал собственные иконки, убран из App-backed пакета. Промежуточная установка с tg-workflow также снята; в списке остался один рабочий @tg.

## Ожидает первого входа

Владелец ещё не завершил получение Telegram API ID/hash: my.telegram.org ответил «Too many attempts». Первый QR-вход, 2FA, чтение реальных переписок, второй именованный аккаунт, восстановление Telegram-сессии после перезапуска и визуальные проверки композера/светлой темы пока не подтверждены. Заглушки и успешный запуск сервера не заменяют эти проверки.

Это состояние конкретного экземпляра автора. При самостоятельном запуске нужно зарегистрировать собственное Telegram API-приложение, настроить свой сервер и HTTPS-адрес, создать своё MCP App и заменить привязку. Публикуемые идентификаторы приложения и адрес сервера не содержат разрешений для входа в чужой аккаунт.

Доступен backend на Bun с systemd/nginx. Dockerfile исходного проекта требует исключённый frontend и в этот снимок не входит. Живые секреты, сессии, базы, логи, SSH-доступ и одноразовая ссылка настройки в репозиторий не включены.
