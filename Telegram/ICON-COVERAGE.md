# Приёмка кастомных иконок tg

Утверждён круглый знак ImageGen A. Файлы и SHA-256 фиксированы в `app-assets/manifest.json`. В переносимом пакете все четыре поля темы заданы явно; один цветной знак подходит обеим темам и намеренно используется в обеих. Для личного App иконка отдельно загружена при регистрации. Пакет App-only 1.0.2 сохраняет оформление App и убирает необязательный skill, который веб-интерфейс показывал generic-кубом.

Серверные aliases `icon-128.png`, `icon-256.png`, `icon.png` также содержат утверждённый знак. Старый SVG Chatroost не должен обслуживаться ни одним публичным маршрутом или ссылкой. При изменении ресурсов используйте версии URL/пути, чтобы кеш не оставил старую иконку.

Для завершения требуется реальная визуальная проверка всех доступных слотов. Автоматический verifier подтверждает файлы, ссылки, размеры, бюджет upload и контрольные суммы; он не доказывает, что ChatGPT отобразил конкретное поле. Пока App не зарегистрирован с кастомным upload или видимый слот показывает generic-значок, соответствующая часть остаётся незавершённой.

В системном модальном окне подключения ChatGPT имеется схема из четырёх узлов. Это пиктограммы платформы, для которых App manifest не предоставляет настройки; их замена не заявлена. Они не подменяют отдельно проверенные логотипы App. Переносимый пакет в вебе показывал generic-значок, поэтому личное веб-подключение переведено на отдельную App-backed регистрацию; `plugin/` сохранён как переносимый исходник.

Skill не нужен для работы уже зарегистрированного MCP App. В App-only пакете остаются настоящий `.app.json`, корневой манифест и синхронный legacy-манифест; инструменты описывает сервер. Инструкция `tg-workflow` сохранена в `plugin/` для самостоятельного/desktop-использования. Обходных параметров оформления, не поддерживаемых схемой, нет.

Подробная квитанция развёртывания хранится вне публикуемого комплекта. Успешная сборка или обновление версии сами по себе не закрывают оставшиеся визуальные и авторизационные проверки.
