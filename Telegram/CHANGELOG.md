# Изменения @tg

## 0.1.0 — 25 октября 2026

- Подготовлен личный плагин `tg` с удалённым MCP по HTTPS и OAuth DCR для ChatGPT и Codex.
- Выбран и включён круглый кастомный знак ImageGen — вариант A. Явно заданы логотипы и иконки композера для светлой и тёмной тем; подготовлены отдельные файлы для App upload, сервера, инструментов и страниц подключения.
- В базу взят фиксированный снимок `mcp-telegram-cloud` 2.63.3. Локальные доработки направлены на именованные аккаунты, явный выбор отправителя, браузерную настройку и раздельные разрешения MCP-клиентов.
- Добавлены инструкции самостоятельного запуска, карта иконок, воспроизводимая упаковка и проверка состава архивов.

Работа реальных Telegram-команд подтверждается только после подключения аккаунта владельцем. Итоговый набор команд определяется обнаруженным каталогом развёрнутого сервера; каталог chigwell целиком автоматически не добавлен.
